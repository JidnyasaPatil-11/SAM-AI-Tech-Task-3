# Student Record Management System in C++

## Project Overview

The Student Record Management System is a C++ console-based application designed to manage student records efficiently.

The system allows users to add, display, search, update, and delete student records through a simple menu-driven interface.

## Features

- Add new student records
- Display all student records
- Search for a student using Roll Number
- Update student information
- Delete student records
- Simple and user-friendly console interface
- Menu-driven program

## Student Information

The system stores the following information:

- Roll Number
- Student Name
- Course/Branch
- Marks

## Technologies Used

- Programming Language: C++
- Header Files: iostream, iomanip, string

## Concepts Used

- Structures
- Arrays
- Functions
- Loops
- Conditional statements
- String handling
- Menu-driven programming

## How It Works

When the program starts, a main menu is displayed.

The user can select an operation:

1. Add Student Record
2. Display All Students
3. Search Student
4. Update Student Record
5. Delete Student Record
6. Exit

Student records are stored during program execution and can be managed using the available options.

## How to Run

1. Open `StudentRecordManagement.cpp` in a C++ compiler or online compiler.
2. Compile and run the program.
3. Select an option from the main menu.
4. Enter the required student information.
5. Use the available options to manage the records.
6. Select Exit to close the program.
